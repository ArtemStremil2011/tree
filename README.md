# 🌳 Семейное древо

Веб-приложение для создания и ведения генеалогического древа. Позволяет пользователям строить свою родословную, добавлять фотографии, документы и биографическую информацию.

## ✨ Возможности

* 🔐 **Регистрация и авторизация** — каждый пользователь имеет доступ только к своему древу
* 👤 **Добавление людей** — имена, аватарки, биография, даты жизни
* 📎 **Загрузка файлов** — фотографии, документы, сканы (до 10MB)
* 🌳 **Визуальное дерево** — автоматические линии связей между родственниками
* ✏️ **Редактирование** — изменение данных и удаление записей
* 🔍 **Масштабирование** — удобный просмотр больших деревьев (50% - 150%)
* 📱 **Адаптивный дизайн** — работает на компьютерах и мобильных устройствах

## 🛠 Технологии

* Python 3.13
* Django 6.0
* SQLite3 (разработка)
* HTML5, CSS3
* JavaScript (SVG для отрисовки связей)

## 📦 Установка

1. Клонируй репозиторий:
```
git clone https://github.com/твой-username/семейное-древо.git
cd семейное-древо
```

2. Создай виртуальное окружение:
```
python -m venv venv
```

3. Активируй окружение:
   * Windows: `venv\Scripts\activate`
   * Mac/Linux: `source venv/bin/activate`

4. Установи Django:
```
pip install django
```

5. Примени миграции:
```
python manage.py migrate
```

6. Создай суперпользователя (для админки):
```
python manage.py createsuperuser
```

7. Запусти сервер:
```
python manage.py runserver
```

8. Открой в браузере: `http://127.0.0.1:8000`

## 🚀 Использование

1. Зарегистрируйся или войди в систему
2. Нажми "Добавить человека"
3. Заполни имя, добавь фото и информацию
4. Укажи родителей (если они уже есть в древе)
5. Просматривай готовое дерево с линиями связей
6. Добавляй файлы к каждому человеку
